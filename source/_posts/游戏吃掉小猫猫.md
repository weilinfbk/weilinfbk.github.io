【开源二创】基于 EatKano，打造一款 Material Design 3 风格的硬核网页游戏

摘要：最近我基于知名开源网页小游戏 EatKano 进行了一次深度二创，不仅将游戏主题替换成了可爱的猫耳少女，还将 UI 全面重构为类似 Google Pixel 的 Material Design 3 (M3) 风格，并彻底解决了移动端的多指触控痛点。今天就来分享一下这次“魔改”的心路历程与技术细节。

背景：为什么是 EatKano？
EatKano 是 GitHub 上非常经典的一个开源下落式音游项目。它最吸引我的地方在于其强大的字符串谱面解析引擎（可以直接用代码生成纵连、交互、阶梯等高难度谱面）以及对自定义图片（包含 GIF 动图）的完美支持。

原版虽然功能硬核，但在 UI 视觉和移动端触控体验上还有很大的优化空间。于是，我决定拿起键盘，给它做一次“从皮到骨”的升级。

---


第一步：视觉重构 —— 拥抱 Material Design 3

如果说原来的 UI 是“极客朋克”，那我想要的就是“现代科技感”。Material Design 3（基于 Material You）的核心在于大圆角、色彩分层和扁平但有层次。

1. 定义 M3 色彩令牌 (Design Tokens)

M3 推荐使用 CSS 变量来管理颜色。在暗色模式下，我们不使用纯黑，而是使用深灰偏紫的底色，这会让界面看起来更高级。

```css
:root {
  /* M3 Dark Theme */
  --md-sys-color-background: #1C1B1F;       /* 页面背景 */
  --md-sys-color-surface: #211F26;          /* 卡片面板 */
  --md-sys-color-surface-container: #2B2930;/* 悬浮容器 */
  
  --md-sys-color-primary: #D0BCFF;          /* 主色调（按钮背景） */
  --md-sys-color-on-primary: #381E72;       /* 主色上的文字 */
  --md-sys-color-secondary-container: #4A4458; /* 次级按钮背景 */
  
  /* 标志性胶囊圆角 */
  --md-sys-shape-corner-full: 999px;
}
```

2. 按钮与组件的 M3 化

把原来的方形或小圆角按钮，全部换成 M3 的 Filled Button（如 Start Game）和 Tonal Button（如 Settings）。加上 transition 和按压水波纹效果，点击手感瞬间提升。

```css
.m3-button {
  border-radius: var(--md-sys-shape-corner-full);
  padding: 12px 24px;
  font-weight: 500;
  border: none;
  cursor: pointer;
  transition: all 0.2s cubic-bezier(0.2, 0, 0, 1);
}
.m3-button-primary {
  background-color: var(--md-sys-color-primary);
  color: var(--md-sys-color-on-primary);
}
.m3-button:active {
  transform: scale(0.95); /* 按下时微缩，提供物理反馈 */
}
```

第二步：技术攻坚 —— 彻底解决多指游玩 (Multi-touch)

这是本次修改的核心难点。在网页端，传统的 click 或 mousedown 事件天生不支持多点同时触发。这意味着玩家无法同时按下“双押”或“三押”，体验大打折扣。

1. 废弃 Click，拥抱 PointerEvent

现代浏览器提供了 PointerEvent，它完美统一了鼠标、触摸屏和触控笔。每个按下的手指都会触发独立的 pointerdown 事件。

```javascript
// 假设你的 HTML 结构里有四个轨道元素带有 .lane 类
const lanes = document.querySelectorAll('.lane');

lanes.forEach(lane => {
  lane.addEventListener('pointerdown', (e) => {
    // 阻止浏览器默认行为（如长按弹菜单、滑动页面）
    e.preventDefault(); 
    
    const laneIndex = parseInt(lane.dataset.lane);
    
    // 触发音游的核心判定逻辑
    triggerHit(laneIndex); 
    
    // 添加视觉按下反馈
    lane.classList.add('active');
  });

  // 手指抬起
  lane.addEventListener('pointerup', (e) => {
    e.preventDefault();
    lane.classList.remove('active');
  });

  // 处理手指滑出轨道范围的情况
  lane.addEventListener('pointercancel', (e) => {
    lane.classList.remove('active');
  });
});
```

2. 必须加上的 CSS 防误触护甲

在移动端浏览器里，手指疯狂点击屏幕很容易触发页面的缩放或滑动。必须在游戏容器上禁用这些手势：

```css
.game-container {
  touch-action: none; /* 告诉浏览器：别插手，触摸事件我自己处理 */
  user-select: none;  /* 禁止选中文字 */
  -webkit-touch-callout: none; /* 禁止 iOS 长按弹出菜单 */
  -webkit-user-select: none;
}
```

第三步：保留原版的“硬核”基因

在改版的过程中，我保留了 EatKano 那些让音游老玩家狂喜的设定：

1. 垂直判定 (Vertical Judgement)：在设置中开启后，判定范围从原本的一条线变成了一个面。配合多指游玩，极大地降低了手机端的断触概率。
2. 快捷谱面预设：保留了 Trill（交互）、Staircase（阶梯）、Triple Jack（三纵连）等一键生成按钮。
3. GIF 谱面整活：依然支持上传 GIF 动图作为音符。你完全可以把音符替换成各种搞笑表情包，做成一期“阴间”实况视频。

总结与部署

经过这一番改造，现在的 Eat the Cat 不仅有着精致的 M3 暗色 UI，更拥有了不输原生 App 的多指触控体验。

整个项目是纯前端（HTML/CSS/JS），你可以直接利用 GitHub Pages 或 Vercel 免费部署，把链接发给朋友们“受虐”。由于截图里我的最高分只有 3 分（存活 0.81 秒），已经被群友疯狂嘲笑了，欢迎大家去挑战更奇葩的谱面！
